# CS-M

CS-M 是一款开源的桌面端数据建模与业务画图设计工具，面向数据平台建设与业务系统架构中的结构设计、业务建模、图谱绘制与交付场景。本项目基于开源项目 [PDManer](https://github.com/roberGroup/PDManer) v4.9.4 进行二次开发，当前发布 **v0.5.0 版本**（企业级统一建模、全生命周期指标平台与平台级 AI 智能辅助终极整合版本）。

## 功能特性

### v0.5.0 新增核心能力（企业建模、指标平台与平台 AI 终极整合）

- **企业级全域统一建模体系（Enterprise Modeling）**：
  - **企业首页架构画布**：用矩形、文字、分组与关系图引用（缩略展示）四类节点拖拽绘制企业架构，支持连线、撤销、缩放与自适应包围盒。
  - **概念-逻辑实体显式关联**：显式多对多关联映射、端点失效保护、双向索引反查、级联删除影响分析（`linkDeletionImpact`）与跨分支导入重映射。
  - **模型全景资源总览**：跨概念、逻辑、物理三层的模型与关系图数量统计、分类（数据域/主题域合计）汇总、物理表分层分布、数据库分布与概念-逻辑关联覆盖率；模型与关系图统计可下钻查看清单（下钻清单暂不支持关键字检索）。
  - **模型前向工程生成引擎**：逻辑实体到物理表的批量生成、数据库类型映射解析、逻辑前缀清洗、表名冲突检测与无损合并。
- **全生命周期指标平台（Metric Platform）**：
  - **核心定义与版本化治理**：原子指标、派生指标、复合指标三类口径规范，支持多版本（1.0/1.1）不可变发布、草案修订、循环依赖检测与部门口径分叉（分叉口径可修订）。
  - **发布内容哈希**：仅用于完整性校验——导入时校验失败整体拒绝该来源指标库；只检测内容改动，非防篡改、不证明来源（未发布版本起由 32 位 FNV 改为 SHA-256 并在导入时校验）。
  - **统一数据字典**：覆盖部门、通用维度、计算限定、统计周期、计量单位五大分类字典，字典条目自身做值类型校验，被引用条目受保护（拒绝删除并列出引用位置，不做级联删除）；未发布版本起，只要存在任一字典条目，指标的单位/维度/部门即按字典严格校验。
  - **指标与模型绑定**：指标可绑定物理表/逻辑实体（计算来源、物化、消费、语义匹配等关系）；字段映射结构包含时间、过滤、维度、事实键字段，当前界面仅可设置时间字段映射。未发布版本起，原子指标的就绪状态按来源在场、物理实体、已确认计算绑定与时间字段映射动态判定（派生/复合指标沿用发布快照）。
  - **跨层血缘分析与影响传播**：可视化依赖网络与计算血缘图谱，支持声明来源穿透、传递影响计算、端点失效追踪与精准互跳。
- **平台级 AI 智能辅助引擎（Platform AI）**：
  - **主进程 AI Broker**：AI 请求由主进程 Broker 代发，密钥不落盘、不经 IPC 与日志回传，日志脱敏；适配 OpenAI 兼容协议（如 DeepSeek）与 Anthropic Claude，可连接本机 loopback 地址上的本地模型。暂不支持系统代理设置与流式输出（见 [docs/ROADMAP.md](docs/ROADMAP.md)）。
  - **智能辅助面板**：画布与建模双面板集成；通过通用对话生成变更计划（无专用的需求拆解、字段推荐流程）；SQL DDL 本地确定性解析提取表结构（支持 MySQL、PostgreSQL 方言）；模型质量规则巡检（规则本地执行，仅“生成修复候选”调用 AI）。
  - **事务化变更执行**：基于纯函数式 Plan-Preview-Apply 机制，支持严格 ReadSet 指纹校验、确定性 PlanHash、幂等回放与撤销（Undo）：执行引擎支持多步撤销，界面当前仅能撤销最近一次变更。

### v0.4.0 核心能力（Chen ER 专业画板与绘图自动保存）

- **Chen 专业画板（Chen ER Studio）**：
  - **完整陈氏模型体系**：强/弱实体、联系/标识联系、普通/复合/多值/派生/键/部分键属性、角色基数与完全参与约束。
  - **语义规范检查与多画布**：内置未命名、孤立角色、弱实体缺少标识联系、同实体下属性重名等语义校验；支持旧草图多画布升级。
  - **现代桌面设计体系**：专业蓝色主题、紧凑图形库、悬浮图形名称提示、右键图形收藏与图层管理器。
- **连续自适应画布与交互提升**：
  - **连续自适应画布**：取消固定纸张限制与视口裁剪，画布工作区按图形与连线实际包围盒自动延展并支持负坐标。
  - **平移手势两栏临时收起**：手形工具平移或按住 `Space` 拖动画布时临时折叠侧边栏扩大视野，松开鼠标精准还原面板与选区，杜绝坐标跳动。
  - **无缝连接与原位编辑**：图形端口直接拖拽建立连接线；原位文字双击编辑、点击画布空白即提交并合并为单步撤销。
- **绘图日志自动保存与生命周期屏障（Persistence Engine）**：
  - **主进程增量日志 (WAL)**：毫秒级响应图形拖拽与编辑，后台自动合并检查点，彻底防御意外断电与异常崩溃。
  - **安全生命周期关闭屏障**：应用退出、窗口关闭或快捷键重载时拦截未落盘状态，提供保存等待与本机恢复副本导出能力。
  - **损坏日志受控恢复**：支持坏日志前缀安全隔离、原样备份与应急恢复，保障工程资产万无一失。

### v0.3.0 核心能力（业务建模与分类画图平台）

- **多模块协同架构（Multi-Module Architecture）**：
  - 在数据建模（Data Modeling）基础上，原生集成业务建模（Business Modeling）与画图平台（Drawing Platform）两大核心模块。
  - 支持按项目需要灵活启用/切换模块，提供主工作台顶部导航切换、首页模块卡片与分类过滤。
  - 内置工程文件读写守卫与只读安全保护，保障多模块共存下的数据持久化安全。
- **业务建模工作台（Business Modeling）**：
  - **业务对象（Business Objects）**：支持高阶业务领域实体定义与属性抽象，衔接业务语义与底层数据模型。
  - **业务流程（Business Processes）**：提供可视化流程图编排设计，支持泳道、活动节点、判定分支与流转连线。
  - **业务规则与角色（Rules & Roles）**：支持业务规则的结构化表达（条件、结果、适用范围），提供参与者角色定义，流程泳道可关联角色。
- **分类画图平台（Drawing Platform）**：
  - **9 种图类型**：流程图、泳道图、架构图、UML 用例图、UML 类图、ER 概念图（陈氏 ER）、思维导图、组织结构图、UML 时序图。其中流程图、泳道图、架构图、UML 用例图、UML 类图共用同一通用图形编辑器（仅图形包与模板不同），ER 概念图在其上启用陈氏专用画板，思维导图与组织结构图使用树编辑器，UML 时序图使用时序编辑器。
  - **27 个起始模板（画图 21 + 业务建模包 3 + 数据建模包 3）**：画图模板覆盖订单退款、采购审批、电商与数据平台分层架构、需求拆解导图、订单与权限类图、登录鉴权时序、图书借阅、课程选修等场景；业务建模包为订单审批、采购入库、客户准入；数据建模包为订单概念/逻辑/物理模型。支持一键初始化与自由修改。
  - **可视化编辑器**：通用图（Graph）、层级树（Tree）、交互时序（Sequence）三类编辑画布与属性检查器，支持样式主题与图层管理；语义检查目前覆盖陈氏 ER（业务流程另有流程检查）。
  - **纯 JSON 文档格式与多画布**：通用图与陈氏 ER 支持单文档多画布（思维导图、组织结构图、时序图当前为单画布），矢量 SVG/PNG 导出，本机草稿自动保存与恢复机制。

### v0.2.0 核心能力（数仓模型目录与概念建模）

- **数仓分层模型目录（Model Catalog）**：支持多层数仓模型分层（如 ODS / DWD / DWS / ADS / DIM 等自定义分层）与数据域/主题域分类管理，统一纳管概念实体、逻辑实体与物理表，支持多重归属及旧主题域待归档投影。
- **概念实体建模（Concept Entities）**：支持高阶业务概念抽象建模，提供独立概念实体编辑器、专属紫色卡片标识、实体级 12/18 端口连接，以及独立集合存储，不强制依赖底层物理字段。
- **概念 / 逻辑 / 物理（C/L/P）三层模型与关系图**：
  - **图级别强约束**：概念图（C）、逻辑图（L）、物理图（P）分别对应接收各自层级的实体与节点，防止跨层级错乱拖拽。
  - **多视图联动与反查**：支持按模型层级快速检索、反查定位所属关系图与目录节点，保存/导出时保持 ID 与目录引用完整。
- **工作台资源树增强**：左侧统一模型目录树支持按上下文快捷新建对应层级对象、分层折叠展开、分类筛选及快捷全局搜索。

### 基础核心能力（v0.1.0 继承）

- **关系数据建模**：物理表与逻辑实体的设计、ER 关系图（基于图编辑能力）
- **数据库管理**：多数据库支持、在线/离线 DDL 生成与执行、结构逆向（从数据库反向导入）
- **数据透视**：对表与字段的多维度透视查看
- **数据类型与字典**：数据库方言类型映射、数据字典管理
- **字段标准（数据标准）与规则**：标准字段/数据标准管理、命名与校验规则
- **字段推荐**：录入字段时依据标准字典/已有模型给出推荐
- **版本管理与导入导出**：工程版本管理（版本差异比较覆盖物理表与视图）、工程/模块导入导出，与 PDManer 工程文件格式保持导入兼容
- **新工作台 UI**：重构后的现代化工作台界面（替代旧版经典布局）

## 平台支持

| 平台 | 架构 | 安装包格式 | 说明 |
| --- | --- | --- | --- |
| Windows | x64 | NSIS 安装包（.exe） | 本版本默认提供 x64 |

## 下载与安装

官方发布入口为 GitHub Releases：<https://github.com/CHENSHISHEN/CS-M/releases>。

请在 Release 页面下载对应操作系统的安装包：
- **Windows (x64)**：`CS-M-win_x64_v0.5.0.exe`
- **macOS Apple Silicon (arm64)**：`CS-M-mac_arm64_v0.5.0.dmg`
- **macOS Intel (x64)**：`CS-M-mac_x64_v0.5.0.dmg`

校验文件（SHA-256）可同步在 Release 页面下载 `SHA256SUMS.txt` 进行比对。

> 说明：本项目未配置商业代码签名证书，产物为未签名安装包；macOS 首次打开需在“系统设置 - 隐私与安全性”中允许，Windows SmartScreen 可能提示未知发布者。也可以通过源码自行构建获取安装包。

## 环境要求与源码开发

| 依赖 | 要求 | 说明 |
| --- | --- | --- |
| Node.js | 本次验证环境：24.11.1 | 构建脚本已内置 webpack 4 与新版 Node/OpenSSL 3 的兼容处理（自动以 `--openssl-legacy-provider` 启动），无需手工设置环境变量；其他版本需通过 preflight 和实际构建验证 |
| npm | 本次验证环境：11.6.2 | 使用仓库锁文件执行 `npm ci` |
| Java（可选） | JRE/JDK 8+ | 以下能力依赖 Java（内置 `pdmaner-java.jar`，通过 `java` 命令或应用内设置的 JAVA_HOME 调用）：**Word 文档导出、Excel 导入/导出（含标准字段 Excel）、PowerDesigner/DDL 文件导入解析、数据库连接/逆向工程/在线执行 DDL**。未安装 Java 时上述功能不可用，但建模、ER 图、工程文件（.chnr/.json）保存与导入导出、Markdown/HTML 导出、数据字典、版本管理等不依赖 Java，仍可正常使用 |

开发步骤：

```bash
git clone https://github.com/CHENSHISHEN/CS-M.git
cd CS-M
npm ci                       # 安装根目录依赖（含构建链，与 CI 一致）
npm ci --prefix app          # 安装应用运行时依赖（双 package 布局）
npm start                    # 启动开发模式（webpack dev server + Electron）
```

## 测试

`npm test`（即 `node tests/run-all.cjs`）逐个运行 40 个测试文件（含单元/契约测试，均为 Node 脚本，不含 GUI 冒烟测试），每个文件在独立子进程中运行并汇总 PASS/FAIL/SKIP；未安装 Java 时 `tests/workbook-branding.cjs` 显式 SKIP。`tests/gui-smoke.cjs` 依赖 Playwright 与 Electron，不在 `npm test` 内。

## 从源码构建安装包

先执行前置检查（可选但推荐）：

```bash
npm run preflight -- win          # 检查 Windows 包构建条件
npm run preflight -- mac-arm64    # 检查 macOS arm64 包构建条件
```

构建产物输出到 `dist/` 目录：

```bash
npm run package-win          # Windows NSIS x64（.exe）
npm run package-mac-arm64    # macOS Apple Silicon（.dmg）
npm run package-mac-x64      # macOS Intel（.dmg）
npm run package-mac          # macOS 双架构各出一个 .dmg
```

说明：

- **macOS 交叉构建 Windows**：本次 electron-builder 23.3.3 实际构建会自动下载 Wine 等兼容工具到构建缓存，无需全局手工安装 Wine。Apple Silicon 主机需能运行 x86_64 构建工具（本机 Rosetta 检查通过）；也可使用仓库的 Windows 原生 CI 工作流。Windows 安装包的构建验证与实机安装运行验证分别记录。
- 首次打包需联网下载 Electron 运行时与 NSIS 等构建工具（国内网络已在 `.npmrc` 配置镜像）。
- 本项目未配置代码签名证书，产物为**未签名**安装包；macOS 首次打开需在"系统设置-隐私与安全性"中允许，Windows SmartScreen 可能提示未知发布者。
- `npm run build` 仅产出 Web/主进程构建文件到 `app/build`，不打安装包。
