# CS-M 0.5.0 UAT

> 当前版本以 `package.json` 的 `version` 为准：**0.5.0**。`main` 上另有 v0.5.0 之后合入、尚未发布的修改（见 [CHANGELOG](../CHANGELOG.md)“未发布（Unreleased）”节），下表中标注“未发布”的项只能用 `main` 源码构建的应用验收。下方“历史记录（0.1.0）”保留首发 UAT 原文，不代表当前状态。

## 本轮验收目标

自动化测试（`npm test`，见 [ACCEPTANCE.md](./ACCEPTANCE.md)）只覆盖纯逻辑、契约与源码静态断言，**不启动 Electron、不操作界面**。本轮 UAT 用于在真实桌面环境中人工确认这些界面行为。截至本文更新，下表各项**尚未执行人工验收**，状态均为“待验收”；执行后请在问题反馈中注明平台、版本与结果。

## 准备

1. 发布版：从 GitHub Releases 获取 v0.5.0 安装包。未发布修改：在 `main` 上执行 `npm ci`、`npm ci --prefix app` 后 `npm start`，或按 README 的打包命令自行构建。
2. 使用新建空项目、内置样例或存量工程的**副本**，不要直接使用真实业务工程。
3. 单实例：`main` 构建的应用再次启动只会聚焦已有窗口；不要与 v0.5.0 同时运行。
4. 普通建模不要求 Java；数据库逆向、DDL 文件解析、Word/Excel 等 Java 能力需先配置可用的 Java。
5. 安装包未使用发布者证书签名或 Apple 公证。

## 历史记录（0.1.0）

以下为 0.1.0 首发 UAT 的原始内容，按原文保留（仅调整标题层级），其中“当前”均指 0.1.0。

### CS-M 0.1.0 首发基线 UAT

#### 本轮验收目标

确认独立 CS-M 仓库与安装包包含约定的首发基线：新工作台、原有关系建模及数据库交付能力、字段推荐和数据标准。原 PDManer 工程目录保持原样；CS-M 运行不依赖该目录。

验收范围围绕当前 v0.1.0 提供的核心功能进行，功能说明见 [BASELINE.md](./BASELINE.md)。

#### 安装与准备

1. 从 GitHub Releases 或本地 `dist/` 获取对应系统和架构的安装包。
2. macOS Apple Silicon 使用 arm64 DMG，Intel 使用 x64 DMG；Windows 使用 x64 NSIS EXE。图标应为 README 相同的蓝紫色折叠 M。
3. 创建一个新的测试目录，用空项目或内置电商/教学样例验收。需要验证存量工程时，使用其副本。
4. 普通建模不要求 Java。测试数据库逆向、DDL 文件解析、Word/Excel 相关 Java 能力时，先配置可用的 Java；现场验证环境与限制见验收记录。
5. 安装包未使用发布者证书签名或 Apple 公证。Windows 的实际安装运行需要 Windows 设备完成；macOS 交叉构建成功不能代替这一项。

#### 建议验收顺序

| 检查项 | 操作 | 预期 |
| --- | --- | --- |
| 安装与产品身份 | 安装并启动对应平台的 CS-M | 应用名称、图标、版本为 CS-M 0.1.0；首页 Logo 正常显示，不覆盖内容 |
| 新建与打开 | 新建空项目；打开内置样例副本；关闭后重开 | 直接进入新工作台，工程可读写；没有经典布局切换入口 |

| ER 关系图 | 打开示例图、选中表、查看属性引用、移动节点与缩放 | 节点和连线正常；属性位于右侧；图保存后重开有效 |

| 工作台布局 | 调整窗口、拖动资源/属性栏、切换主题和文档 | 状态栏在底部，属性在右侧，编辑区可见，Logo 不溢出 |
| 边界核对 | 浏览主导航和新建入口 | 各功能入口与基线说明保持一致 |

数据库真实连接测试需要专用连接环境。本地文件/Java 解析通过不代表数据库驱动和每种数据库连接均已验证。
